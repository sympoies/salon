# Development log - 2026-11

## 2026-11-01 - Parse session notices inside the Claude paste wrapper

### Result

- A session notice that Claude records inside one whole paste wrapper
  (`<pasted_content id="...">` ... the same id on the closing tag) now parses as
  that notice, with the same kind, source, id and body as the unwrapped text, so
  a long bootstrap or handover prompt renders as a notice instead of a user
  bubble with its marker visible. A wrapper with mismatched ids, an unclosed
  wrapper, text around the wrapper or a wrapped plain message stays ordinary
  text. The parser unwraps through the existing paste helper, so no consumer
  changes.

### Why / context

- The marker must start the message, and a wrapper put the tag first. Fixes #224.

### Evidence

- Parser tests cover a wrapped and an unwrapped notice, a sample shaped like a
  Claude transcript record, and the non-notice wrapper variants. The repository
  gate result is recorded on the pull request.

## 2026-11-01 - Remove the Scope session filter

### Result

- The Session filters panel no longer offers Scope: the field, its chip, its
  counts and the `scope` filter dimension are gone. A `scope` value left in
  stored or URL state by an earlier version is ignored and never hides
  sessions. Workspace stays the only grouping facet.
- The `sessionScopes` UI extension is removed. Its role override continues as
  the separate `sessionRole` hook, which receives the records and the list
  extension data and returns a function naming each record's role for the
  Roles facet. The scope navigation field of a badge's lineage callback is gone.
- The lineage ordering helpers are renamed `LineageRecord`,
  `lineageRecordKey` and `lineageParents`; the old `ScopeRecord`,
  `scopeRecordKey` and `scopeParents` names stay as deprecated aliases for one
  release.

### Why / context

- The multi-select Workspace facet already covers grouping, and the daemon
  session record calls the field `workspace`, so one term remains.

### Evidence

- Focused tests cover the missing Scope field and chip, an ignored stored
  scope value, a host role override in the Roles facet and the exported
  aliases. The repository gate result is recorded on the pull request.
