## 2026-10-29 - Paper theme for the terminal, viewer and remaining surfaces

### Result

- The xterm canvas follows the resolved theme: an open terminal repaints when
  the setting or the OS preference changes, with no reconnect or reload. Paper
  uses the page canvas as its background so the pane has no seam, ink text, and
  a 16-colour ANSI palette in which every colour reads at 4.5:1 or more. The
  dark palette is the unchanged Night Owl theme, now in `terminalTheme.ts`.
- The Shell page, terminal key bar and link-hover popup follow the theme. Code
  blocks, tables, quotes, links and Markdown text were already on theme tokens;
  they are now covered by captures. The image viewer takes a Paper scrim and

## 2026-10-29 - Paper light theme with a System / Dark / Paper setting (core surfaces)
