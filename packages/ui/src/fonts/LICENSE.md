# Bundled fonts

`BlexMonoNerdFontMono-Regular.woff2` and
`BlexMonoNerdFontMono-Bold.woff2` are WOFF2 subsets of BlexMono Nerd Font Mono,
the Nerd Fonts patched IBM Plex Mono family. Their bytes are preserved from the
reviewed core snapshot.

The font software remains under the SIL Open Font License 1.1. It is separate
from this repository's MIT-licensed code. IBM's copyright notice and the full
font license are included in [OFL.txt](OFL.txt); the upstream project's combined
font and source-code licensing notice is in
[NERD-FONTS-LICENSE](NERD-FONTS-LICENSE). The MIT section applies to the upstream
patcher source, which is not bundled here.

License notices were obtained from the
[upstream font directory](https://github.com/ryanoasis/nerd-fonts/tree/adbd16ab7ca911eaca7ce3b0f2b7994207c7ecae/patched-fonts/IBMPlexMono)
and [project license](https://github.com/ryanoasis/nerd-fonts/blob/adbd16ab7ca911eaca7ce3b0f2b7994207c7ecae/LICENSE).
The reserved base-family name is "Plex"; these patched files retain the BlexMono
Nerd Font name. The package build carries these notices beside the font files.
